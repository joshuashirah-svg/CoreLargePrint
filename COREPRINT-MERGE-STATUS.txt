CORELARGEPRINT / CTP100LG — COREPRINT RASTER INTEGRATION

Integrated into app/src/main/java/com/corelargeprint:
- CorePrintProtocol.java now creates image/text command headers, feed packets,
  18-row zlib raster blocks, frame length fields, CRC-8, and 0xFF terminators.
- MainActivity now sends CorePrint raster jobs over the previously confirmed
  Bluetooth Classic SPP transport. Generic ESC/POS printing is disabled.
- Receipt text is rendered into a 576-dot bitmap. Phone image selection,
  preview, remove, and print controls remain available.
- Writes are split into 512-byte chunks with short inter-chunk pacing.

Local protocol self-test passed in the preparation environment:
- feedPaper(20) exact bytes
- image/text header exact bytes
- 51 78 CE marker and big-endian lengths
- zlib payload round-trip
- frame CRC-8 verification

Still not physically verified:
- Actual output on the user's CTP100LG printer.
- Exact original CorePrint pixel lookup-table output and any remaining model-
  specific command sequencing not present in the supplied extracted snippets.
- Whether the printer expects additional inter-block pacing or an end marker.
